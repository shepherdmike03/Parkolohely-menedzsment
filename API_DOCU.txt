2. /new_spot
    --> Letre lehet hozni vele uj parkolohelyeket.
    --> Meg kell adni a 'DARAB' szamot (hogy hany parkolohely fog letezni [1 < n < 500])
    --> Meg kell adni a kategoriaId -t ami lehet (1,2,3)
               
               kategoria_id | kategoria_nev
              --------------+---------------
                          1 | Szemelyauto
                          2 | Motor
                          3 | Teherauto
              (3 rows)


       * HA A KATEGORIAK VELETLENUL NEM GENERALODNAK LE, a  kovetkezo parancsal lehet oket insertelni.
         
                        sudo docker compose exec db \
                        psql -U sa -d parkolo_foglalas \
                        -c "
                        INSERT INTO kategoria (kategoria_nev)
                        VALUES
                            ('Szemelyauto'),
                            ('Motor'),
                            ('Teherauto')
                        RETURNING *;
                        "


          Parancs:
            curl   -X POST   http://localhost:3333/new_spot   -H "Content-Type: application/json"   -d '{
                "darab": 3,
                "kategoriaId": 2
            }'

4. /blacklist_person

    --> egy bizonyos tulajdonost fel lehet rakni a tilto listara
    --> meg kell adni a tulajdonos ID-jat
    --> meg kell adni a tiltas okat
    --> opcionalisan meg lehet adni a tiltas veget
    --> ha a 'tiltasVege' null, 
      akkor a tiltas hatarozatlan ideig ervenyes
    --> ha a tulajdonos mar aktiv tiltason van,
      akkor a szerver nem hoz letre meg egy tiltast


          Parancs:
            curl -s \
              -X POST \
              http://localhost:3333/blacklist_person \
              -H "Content-Type: application/json" \
              -d '{
                "tulajdonosId": 1,
                "ok": "tolvaj",
                "tiltasVege": "2026-09-01T12:00:00Z"
              }' | jq

          Vart Kimenet:

            {
              "tiltasId": 1,
              "tulajdonosId": 1,
              "tulajdonosNev": "Elek Teszt",
              "ok": "tolvaj",
              "tiltasKezdete": "2026-08-02T00:50:00Z",
              "tiltasVege": "2026-09-01T12:00:00Z",
              "aktiv": true
            }
      

       Hatarozatlan ideju tiltas:

            curl -s \
              -X POST \
              http://localhost:3333/blacklist_person \
              -H "Content-Type: application/json" \
              -d '{
                "tulajdonosId": 2,
                "ok": "Kesett",
                "tiltasVege": null
              }' | jq


        Ha a tulajdonos mar tiltva van:

            {
              "error": "A tulajdonos mar aktiv tiltas alatt all. Aktualis ok: tolvaj"
            }


5. /new_reservation

    --> Egy bizonyos jarmuhoz lehet uj foglalast letrehozni.
    --> Meg kell adni a jarmu ID-jat.
    --> Meg kell adni a foglalas kezdeti es veg idopontjat.
    --> A kezdeti idopont nem lehet multbeli.
    --> A veg idopontnak kesobb kell lennie mint a kezdeti idopont.


    --> A szerver automatikusan ellenorzi:

          1. Letezik e a jarmu.
          2. A jarmu tulajdonosa tiltott e.
          3. Van e a jarmunek masik utkozo foglalasa.
          4. Van e megfelelo meretu szabad parkolohely.
          5. A kivalasztott parkolohely szabad e a megadott idopontban.


    --> A szerver automatikusan a legkisebb megfelelo helyet valasztja ki.

          Motor:
            Motor hely
              --> ha elfogy, Szemelyauto hely
              --> ha az is elfogy, Teherauto hely

          Szemelyauto:
            Szemelyauto hely
              --> ha elfogy, Teherauto hely

          Teherauto:
            Csak Teherauto hely


    --> Tehat egy Szemelyauto NEM kaphat Motor helyet.
    --> Egy Motor viszont kaphat nala nagyobb helyet.


          Parancs:

            curl -s \
              -X POST \
              http://localhost:3333/new_reservation \
              -H "Content-Type: application/json" \
              -d '{
                "jarmuId": 1,
                "kezdetIdo": "2026-08-03T10:00:00Z",
                "vegIdo": "2026-08-03T12:00:00Z"
              }' | jq


          Vart Kimenet:

            {
              "elfogadva": true,
              "foglalas": {
                "foglalasId": 1,
                "jarmuId": 1,
                "rendszam": "MOTOR-001",
                "tulajdonosId": 1,
                "tulajdonosNev": "Elek Teszt",
                "parkolohelyId": 1,
                "helyAzonosito": "K1-A11B22C3",
                "jarmuKategoria": "Motor",
                "parkolohelyKategoria": "Motor",
                "kezdetIdo": "2026-08-03T10:00:00Z",
                "vegIdo": "2026-08-03T12:00:00Z",
                "erkezesIdo": null,
                "elhagyasIdo": null,
                "letrehozva": "2026-08-02T00:55:00Z",
                "allapot": "TERVEZETT"
              }
            }


    --> A foglalas 'allapot' mezoje a kovetkezo lehet:

          TERVEZETT
            --> A foglalas kezdeti idopontja meg nem erkezett el.

          ERKEZESRE_VAR
            --> A foglalasi idoszak elkezdodott, de a jarmu meg nem erkezett meg.

          PARKOL
            --> A jarmu megerkezett, es jelenleg a parkoloban van.

          LEZART
            --> A jarmu elhagyta a parkolot.

          LEJART
            --> A foglalas vege elmult, de nem lett rendesen lezarva.




    --> Ha a tulajdonos tiltva van:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "TULAJDONOS_TILTOTT",
              "uzenet": "A jarmu tulajdonosa aktiv tiltas alatt all.",
              "tiltasok": [
                {
                  "tiltasId": 1,
                  "ok": "Tobbszori szabalysertes",
                  "tiltasKezdete": "2026-08-02T00:50:00Z",
                  "tiltasVege": "2026-09-01T12:00:00Z"
                }
              ]
            }




    --> Ha nincs megfelelo szabad hely:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "NINCS_MEGFELELO_HELY",
              "uzenet": "A megadott idoszakra nincs megfelelo meretu szabad parkolohely.",
              "tiltasok": []
            }




    --> Ha a jarmunek mar van utkozo foglalasa:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "JARMU_MAR_FOGLALT",
              "uzenet": "A jarmunek mar van atfedo foglalasa.",
              "tiltasok": []
            }
