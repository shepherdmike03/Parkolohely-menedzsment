4. /blacklist_person

    --> egy bizonyos tulajdonost fel lehet rakni a tilto listara
    --> meg kell adni a tulajdonos ID-jat
    --> meg kell adni a tiltas okat

5. /new_reservation

    --> Egy bizonyos jarmuhoz lehet uj foglalast letrehozni.
    --> Meg kell adni a jarmu ID-jat.
    --> Meg kell adni a foglalas kezdeti es veg idopontjat.
    --> A kezdeti idopont nem lehet multbeli.
    --> A veg idopontnak kesobb kell lennie mint a kezdeti idopont.


    --> A szerver automatikusan ellenorzi:

          1. Letezik e a jarmu.
          2. A jarmu tulajdonosa tiltott e.
          3. Van e a jarmunek masik utkozo foglalasa.
          4. Van e megfelelo meretu szabad parkolohely.
          5. A kivalasztott parkolohely szabad e a megadott idopontban.


    --> A szerver automatikusan a legkisebb megfelelo helyet valasztja ki.

          Motor:
            Motor hely
              --> ha elfogy, Szemelyauto hely
              --> ha az is elfogy, Teherauto hely

          Szemelyauto:
            Szemelyauto hely
              --> ha elfogy, Teherauto hely

          Teherauto:
            Csak Teherauto hely


    --> Tehat egy Szemelyauto NEM kaphat Motor helyet.
    --> Egy Motor viszont kaphat nala nagyobb helyet.


          Parancs:

            curl -s \
              -X POST \
              http://localhost:3333/new_reservation \
              -H "Content-Type: application/json" \
              -d '{
                "jarmuId": 1,
                "kezdetIdo": "2026-08-03T10:00:00Z",
                "vegIdo": "2026-08-03T12:00:00Z"
              }' | jq


          Vart Kimenet:

            {
              "elfogadva": true,
              "foglalas": {
                "foglalasId": 1,
                "jarmuId": 1,
                "rendszam": "MOTOR-001",
                "tulajdonosId": 1,
                "tulajdonosNev": "Elek Teszt",
                "parkolohelyId": 1,
                "helyAzonosito": "K1-A11B22C3",
                "jarmuKategoria": "Motor",
                "parkolohelyKategoria": "Motor",
                "kezdetIdo": "2026-08-03T10:00:00Z",
                "vegIdo": "2026-08-03T12:00:00Z",
                "erkezesIdo": null,
                "elhagyasIdo": null,
                "letrehozva": "2026-08-02T00:55:00Z",
                "allapot": "TERVEZETT"
              }
            }


    --> A foglalas 'allapot' mezoje a kovetkezo lehet:

          TERVEZETT
            --> A foglalas kezdeti idopontja meg nem erkezett el.

          ERKEZESRE_VAR
            --> A foglalasi idoszak elkezdodott, de a jarmu meg nem erkezett meg.

          PARKOL
            --> A jarmu megerkezett, es jelenleg a parkoloban van.

          LEZART
            --> A jarmu elhagyta a parkolot.

          LEJART
            --> A foglalas vege elmult, de nem lett rendesen lezarva.




    --> Ha a tulajdonos tiltva van:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "TULAJDONOS_TILTOTT",
              "uzenet": "A jarmu tulajdonosa aktiv tiltas alatt all.",
              "tiltasok": [
                {
                  "tiltasId": 1,
                  "ok": "Tobbszori szabalysertes",
                  "tiltasKezdete": "2026-08-02T00:50:00Z",
                  "tiltasVege": "2026-09-01T12:00:00Z"
                }
              ]
            }




    --> Ha nincs megfelelo szabad hely:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "NINCS_MEGFELELO_HELY",
              "uzenet": "A megadott idoszakra nincs megfelelo meretu szabad parkolohely.",
              "tiltasok": []
            }




    --> Ha a jarmunek mar van utkozo foglalasa:


          Vart Kimenet:

            {
              "elfogadva": false,
              "kod": "JARMU_MAR_FOGLALT",
              "uzenet": "A jarmunek mar van atfedo foglalasa.",

13. /dev/generate_data

    --> Nagyobb mennyisegu tesztadatot lehet vele generalni az adatbazisba.
    --> Letrehoz tulajdonosokat, jarmuveket, parkolohelyeket, tiltasokat es multbeli foglalasokat.
    --> Ez egy fejlesztoi endpoint, tehat production kornyezetben nem ajanlott szabadon elerhetove tenni.


    --> Meg kell adni:

          persons
            --> Hany uj tulajdonost hozzon letre.
            --> Minimum 1, maximum 1000.

          vehiclesPerPerson
            --> Hany jarmuvet hozzon letre minden uj tulajdonoshoz.
            --> Minimum 1, maximum 5.

          spotsPerCategory
            --> Hany uj parkolohelyet hozzon letre kategoriankent.
            --> Minimum 0, maximum 200.

          pastReservations
            --> Hany multbeli foglalast hozzon letre.
            --> Minimum 0, maximum 5000.

          blacklistPercent
            --> Az uj tulajdonosok hany szazaleka keruljon tiltolistara.
            --> Minimum 0, maximum 100.


          Parancs:

            curl -s \
              -X POST \
              http://localhost:3333/dev/generate_data \
              -H "Content-Type: application/json" \
              -d '{
                "persons": 50,
                "vehiclesPerPerson": 2,
                "spotsPerCategory": 20,
                "pastReservations": 60,
                "blacklistPercent": 10
              }' | jq


          Vart Kimenet:

            {
              "batchId": "MEL9JX5A",
              "categoriesUsed": 3,
              "personsCreated": 50,
              "vehiclesCreated": 100,
              "spotsCreated": 60,
              "blacklistsCreated": 5,
              "pastReservationsCreated": 60
            }


    --> A 'batchId' az adott generalasi muvelet egyedi azonositoja.
    --> A visszateritett darabszamok megmutatjak hogy valojaban hany rekord lett letrehozva.

17. /search/vehicles/{id}

    --> Egy bizonyos jarmuvet lehet lekerdezni a jarmu ID-ja alapjan.
    --> A tulajdonos es a kategoria adatait is visszaadja.


          Parancs:

            curl -s \
              http://localhost:3333/search/vehicles/2 \
              | jq


          Vart Kimenet:

            {
              "jarmuId": 2,
              "rendszam": "ABC-123",
              "tulajdonosId": 2,
              "tulajdonosNev": "Gipsz Jakab",
              "kategoriaId": 1,
              "kategoriaNev": "Szemelyauto"
            }


    --> Ha nem letezik jarmu a megadott ID-val:


          Vart Kimenet:

            {
              "error": "nem letezik jarmu ezzel az ID-val: 9999"
            }




18. /search/spots

    --> Parkolohelyeket lehet vele kilistazni, vagy szoveg alapjan keresni.
    --> A 'q' parameter opcionalis.
    --> Ha a 'q' nincs megadva, vagy ures, akkor minden parkolohelyet kilistaz.
    --> Lehet keresni a hely azonositoja, kategoria neve, vagy parkolohely ID alapjan.


          Minden parkolohely kilistazasa:

            curl -s \
              "http://localhost:3333/search/spots" \
              | jq


          Kereses a hely azonositoja alapjan:

            curl -s \
              "http://localhost:3333/search/spots?q=K1-A11B22C3" \
              | jq


          Vart Kimenet:

            [
              {
                "parkolohelyId": 1,
                "helyAzonosito": "K1-A11B22C3",
                "aktiv": true,
                "kategoriaId": 1,
                "kategoriaNev": "Szemelyauto"
              }
            ]


    --> Ha nincs talalat, a szerver ures listat ad vissza:

            []




19. /search/spots/{id}

    --> Kiirja a hely azonositojat, aktiv allapotat es kategoriajat is.

              | jq


          Vart Kimenet:

              "kategoriaId": 1,
              "kategoriaNev": "Szemelyauto"
            }


    --> Ha nem letezik parkolohely a megadott ID-val:


          Vart Kimenet:

            {
              "error": "nem letezik parkolohely ezzel az ID-val: 9999"
            }




20. /search/blacklist

    --> A tiltolista bejegyzeseit lehet vele kilistazni, vagy szoveg alapjan keresni.
    --> A 'q' parameter opcionalis.
    --> Ha a 'q' nincs megadva, vagy ures, akkor minden tiltas bejegyzest kilistaz.
    --> Lehet keresni a tulajdonos neve, a tiltas oka, a tiltas ID-ja, vagy a tulajdonos ID-ja alapjan.
    --> Az 'aktiv' mezo azt mutatja meg hogy a tiltas jelenleg meg ervenyes e.


          Minden tiltas kilistazasa:

            curl -s \
              "http://localhost:3333/search/blacklist" \
              | jq


          Kereses a tulajdonos neve alapjan:

            curl -s \
              "http://localhost:3333/search/blacklist?q=Elek" \
              | jq


          Vart Kimenet:

            [
              {
                "tiltasId": 1,
                "tulajdonosId": 1,
                "tulajdonosNev": "Elek Teszt",
                "ok": "tolvaj",
                "tiltasKezdete": "2026-08-02T00:50:00Z",
                "tiltasVege": "2026-09-01T12:00:00Z",
                "aktiv": true
              }
            ]


    --> Ha nincs talalat, a szerver ures listat ad vissza:

            []




21. /search/blacklist/{id}

    --> Egy bizonyos tiltas bejegyzest lehet lekerdezni a tiltas ID-ja alapjan.
    --> Kiirja a tulajdonos adatait, a tiltas okat, idopontjait es jelenlegi allapotat.


          Parancs:

            curl -s \
              http://localhost:3333/search/blacklist/1 \
              | jq


          Vart Kimenet:

            {
              "tiltasId": 1,
              "tulajdonosId": 1,
              "tulajdonosNev": "Elek Teszt",

              "tiltasKezdete": "2026-08-02T00:50:00Z",
              "tiltasVege": "2026-09-01T12:00:00Z",
              "aktiv": true
            }


    --> Ha nem letezik tiltas a megadott ID-val:


          Vart Kimenet:

            {
              "error": "nem letezik tiltas ezzel az ID-val: 9999"
